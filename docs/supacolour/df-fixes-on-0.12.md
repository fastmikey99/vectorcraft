# DF fixes on VectorCraft 0.12

Status: in progress, 17 October 2026. Base: `a417e806`; branch:
`codex/df-fixes-on-0.12`. Each numbered port is a separate commit. No customer
files, font binaries, Adobe application material or external reviews are used.
The local `plan/` instructions referenced by AGENTS.md are absent in this worktree.

## 1. Direct ICC CMYK conversion — aff6c213

**Ported.** 0.12 still converted through display sRGB/Lab. Restored `to_cmyk_of`
and the CMS entry points, and routed PDF fills and RGB/CMYK image conversion
through them. The wide linear ProPhoto hub avoids sRGB gamut clipping; relative
colorimetric alone remaps black points. Removed the old patch's unused one-step
transform variant. Generic/device spaces retain their existing fallback.

Tests: restored `icc_cmyk_converts_into_another_icc_cmyk_directly` using profiles
generated by the code, plus `direct_cmyk_compensation_only_remaps_relative_black`
for BPC, white, intent/cache separation and rejecting a non-CMYK destination.
Validation: `cargo test -p vectorcraft-color -p vectorcraft-pdf` passed (118 colour and 320 PDF unit tests, plus integration tests); the added BPC test passed separately. `cargo xtask ci` then passed all nine gates, including 119 colour tests. A first CI attempt hit sandbox socket restrictions; the rerun used local socket access. The new test initially assumed a saturation table; it now explicitly checks the generated profile’s unsupported-intent fallback.

## Local validation environment

Homebrew Rust/Cargo 1.97.1; clippy available. Commands use the existing
`/tmp/hybrid-colour-ci-target` cache, `CARGO_PROFILE_DEV_DEBUG=0`,
`CARGO_PROFILE_TEST_DEBUG=0`, `CARGO_INCREMENTAL=0`, `RUSTC_BOOTSTRAP=1`, and
`CARGO_UNSTABLE_BUILD_STD=std,panic_abort` (the installed Rust sources supply the
WASM standard library). `CRAFT_FONTS_DIR` is unset. An initial native build
without these cache/size settings was interrupted and restarted with them.

Revision: 17 October 2026 — begin behavioural ports and synthetic regressions.

## 2. Non-sRGB PDF tags — f1f35863

**Ported and adapted.** Tagged RGB keeps its working/destination numbers and
profile; decoded RGB images convert into that space, and the writer's RGB
colour/blending profile streams are retagged. PDF/A retains its sRGB fallback.
BPC now affects only relative colorimetric RGB transforms. Unlike the old patch,
the colour tag and matching output intent share one profile stream; a different
sRGB output intent must not reuse a stream being retagged. The existing
`preserveSource` refusal for non-sRGB tagging remains: decoded image conversion
is outside that mode's promise.

Tests: restored `tagged_rgb_in_a_wide_space_keeps_its_numbers_and_embeds_its_profile`
using 0.12's fractional writer output, with same/different output intents,
no-catalog tagging, loaded RGB profiles, image readback and PDF/A checks. Restored
the perceptual BPC assertion in the colour tests.

Validation: affected-crate test run passed (119 colour and 323 PDF unit tests,
plus integrations); affected-crate clippy with `--all-targets -- -D warnings`
and `cargo fmt --all -- --check` passed. Full commands are recorded below as
the remaining ports land.

## 3. PNG colour declaration — b4f7f61f

**Ported.** PNG and indexed PNG exports now carry the perceptual sRGB chunk.
Restored `png_exports_say_their_colours_are_srgb`, also checking resolution
metadata and successful decoding for both formats.

Validation: engine (2,263 unit tests) and render (305 unit tests), plus their
integration tests, passed in the affected-crate run. Clippy and fmt passed.

## 4. PDF-compatible .ai crop — 10b56b9c

**Ported as the local print policy.** PDF import applies CropBox clipping to
PDF-compatible `.ai` artwork as well as ordinary PDFs. This intentionally differs
from upstream's off-artboard editing policy; native editing-data restoration is
unchanged. Adapted the layer/path-count, page-spacing and text-stroke tests rather
than importing the old patch's two test ignores. Added a distinct CropBox versus
MediaBox regression. All PDF inputs are synthetic.

Validation: all 323 PDF unit tests and its integration tests passed, including
the cropped-page stroke and spacing cases. Clippy and fmt passed.

## 5. Preferred units on open — f3cbafb4

**Ported.** Renamed `Loaded::with_grid_prefs` to `with_prefs`, retaining 0.12's
resolved-links argument. Both open and revert apply preferred units when the
importer supplies no explicit unit. Native/restored documents and explicitly
unit-sized SVGs retain their units; geometry is not rescaled.

Tests: restored PDF, pixel SVG, inch SVG and native reopen cases, added explicit
SVG points and embedded-native PDF preservation. The SVG size check allows its
parser's existing floating-point rounding.

Validation: all 2,263 engine unit tests and integration tests passed, including
both preferred-unit regressions. Clippy and fmt passed.
