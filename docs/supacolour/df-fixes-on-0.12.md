## 1. Direct ICC CMYK conversion — aff6c213

**Ported.** 0.12 still converted through display sRGB/Lab. Restored `to_cmyk_of`
and the CMS entry points, and routed PDF fills and RGB/CMYK image conversion
through them. The wide linear ProPhoto hub avoids sRGB gamut clipping; relative
colorimetric alone remaps black points. Removed the old patch's unused one-step
transform variant. Generic/device spaces retain their existing fallback.

Tests: restored `icc_cmyk_converts_into_another_icc_cmyk_directly` using profiles
generated by the code, plus `direct_cmyk_compensation_only_remaps_relative_black`
for BPC, white, intent/cache separation and rejecting a non-CMYK destination.
Validation: `cargo test -p vectorcraft-color -p vectorcraft-pdf` passed (118 colour and 320 PDF unit tests, plus integration tests); the added BPC test passed separately. `cargo xtask ci` then passed all nine gates, including 119 colour tests. A first CI attempt hit sandbox socket restrictions; the rerun used local socket access. The new test initially assumed a saturation table; it now explicitly checks the generated profile’s unsupported-intent fallback.

## Local validation environment

Homebrew Rust/Cargo 1.97.1; clippy available. Commands use the existing
`/tmp/hybrid-colour-ci-target` cache, `CARGO_PROFILE_DEV_DEBUG=0`,
`CARGO_PROFILE_TEST_DEBUG=0`, `CARGO_INCREMENTAL=0`, `RUSTC_BOOTSTRAP=1`, and
`CARGO_UNSTABLE_BUILD_STD=std,panic_abort` (the installed Rust sources supply the
WASM standard library). `CRAFT_FONTS_DIR` is unset. An initial native build
without these cache/size settings was interrupted and restarted with them.
